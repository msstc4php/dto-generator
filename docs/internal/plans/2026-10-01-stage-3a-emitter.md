# DTO Generator — этап 3a: Emitter (IR → PHP-код под целевую версию). План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** По `ClassModel` и `TargetProfile` выдать полный исходник PHP-файла DTO в форме, которую диктует целевая версия (spec §6.2). Вывод проверяется побайтными golden-файлами и прогоном на реальных `php:7.4…8.5-cli`.

**Architecture:**
- Вся версия-зависимость формы класса считается в Domain: `TargetProfile::classFormFor(Mutability): ClassForm`. Там решается, promoted ли свойства, какая у них видимость, readonly свойства или класс, есть ли getters и setters и как устроен `with*()`.
- Infrastructure-адаптер `PhpParserEmitter` (порт `Application/Port/CodeEmitter`) механически строит AST через `nikic/php-parser` 5. Ему помогают `TypeRenderer` (нативный тип и PHPDoc-тип), `DocBlock` (сборка PHPDoc с экранированием `*/`) и `GeneratedCodePrinter` (наследник `Standard` с пустыми строками между членами и `declare(strict_types=1);`).
- Этап 3 разделён, как и этап 2:
  - **3a** (этот план) — Emitter и проверка вывода;
  - **3b** — Writer с манифестом, use-case Generate, CLI, golden end-to-end по фикстурам-проектам, PHPStan по выводу, CI.

**Tech Stack:** PHP ≥ 7.4, `nikic/php-parser ^5.0`, PHPUnit 9.6, PHPStan 2 max (`phpVersion: 70400`), deptrac, Rector, CS-Fixer, Infection, Docker `php:<ver>-cli`.

**Spec:** `docs/internal/specs/2026-10-01-dto-generator-design.md`:
- §5.1 — PHP-типы и PHPDoc;
- §5.2 — порядок аргументов конструктора, default;
- §5.5 — PHPDoc, `*/`, `@deprecated`, заголовок `@generated`;
- §6.1 — capabilities;
- §6.2 — форма класса;
- §11.1 — Unit Emitter, golden-профили 7.4, 8.0, 8.1, 8.2, 8.5, проверка на целевой версии;
- §13, этап 3 (часть Emitter).

Атрибуты (этап 5), наследование, enum и discriminator (этап 4) emitter пока отвергает исключением `LogicException`: Build их не порождает.

## Global Constraints

- Исходники и тесты работают на PHP 7.4. Запрещены: `enum`, `readonly`, атрибуты, `match`, union/`mixed`/`static` в сигнатурах, promoted-свойства, именованные аргументы, функции PHP 8+, висячая запятая в списках параметров. Это касается кода генератора. Сгенерированный код использует синтаксис цели.
- PHPStan `level: max` без ignore. Тесты исключений проверяют класс и подстроку сообщения.
- Вывод детерминирован: один и тот же `ClassModel` и `TargetProfile` дают одну и ту же строку. Это критерий успеха 1 спеки.
- Сгенерированный файл:
  - начинается с `<?php`, пустой строки и `// @generated by msstc4php/dto-generator — DO NOT EDIT`;
  - затем `declare(strict_types=1);` и `namespace`;
  - заканчивается переводом строки.
- Имена классов в коде и PHPDoc: класс из того же namespace — короткое имя, любой другой — `\` + FQCN. Секцию `use` emitter пока не строит, импорты появятся с атрибутами на этапе 5.
- Порядок членов класса:
  1. объявления свойств (только без promotion) в порядке `properties`;
  2. конструктор, у которого обязательные параметры идут первыми, а необязательные следом, каждые в порядке `properties`;
  3. по каждому свойству в порядке `properties`: `getX`, `setX`, `withX`.
- Комментарии — на английском, только «почему». Документация — на русском. Даты — UTC.
- Коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Гейт каждой задачи: `make fix && make verify`. Docker-цели (`verify`, `test-targets`) и `make infection` запускаются вне песочницы. В конце этапа MSI ≥ 99 %.
- Работа ведётся в ветке `feat/stage-3a-emitter` от `main`.

## Review Focus

1. **Свойство с именем `clone` при `with*` через `clone`** (7.4/8.0 immutable). Временная переменная `$clone` совпала бы с параметром `$clone`. Ожидается `$copy = clone $this; $copy->clone = $clone;`. Тест — Task 4.
2. **`x-php-name: GLOBALS` или `_GET`.** Параметр `$GLOBALS` даёт фатальную ошибку компиляции сгенерированного файла. Ожидается диагностика ошибки в Builder и инвариант `PropertyModel`. Тест — Task 2.
3. **`description` с `*/`, многострочный, с CRLF.** Ожидается корректный PHPDoc: `*\/`, строки с ` * `, без хвостовых пробелов. Тест — Task 3 и golden-профили (Task 5).
4. **Тип из другого или глобального namespace** (`\DateTimeImmutable`, `\Brick\Money\Money`) в файле с `namespace App\Dto`. Без ведущего `\` и в нативном типе, и в PHPDoc имя разрешилось бы относительно namespace. Ожидается `\`-квалификация в обоих местах. Тест — Task 3.
5. **Необязательное свойство объявлено раньше обязательного.** На 8.0+ «Optional parameter declared before required» даёт deprecation, а позиционные вызовы ломаются. Ожидается, что обязательные параметры идут первыми, а `new self(...)` в `with*` использует тот же порядок. Тест — Task 4. Golden-профили (Task 5) прогоняются на 8.x с error handler, который превращает deprecation в ошибку.

```php
namespace MSSTC4PHP\DtoGenerator\Domain\Target;

use MSSTC4PHP\DtoGenerator\Domain\Shared\AbstractEnum;

/**
 * How an immutable DTO produces a modified copy (spec §6.2, row "with*()").

final class WitherStyle extends AbstractEnum
{
    public const NONE = 'none';
    public const CLONE_ASSIGN = 'clone-assign';
    public const NEW_SELF = 'new-self';
    public const CLONE_WITH = 'clone-with';

    public function isNone(): bool
    {
        return $this->value() === self::NONE;
    }

    protected static function values(): array
    {
        return [self::NONE, self::CLONE_ASSIGN, self::NEW_SELF, self::CLONE_WITH];
    }
}
```

`src/Domain/Target/ClassForm.php`:

```php
<?php

declare(strict_types=1);

namespace MSSTC4PHP\DtoGenerator\Domain\Target;

/**
 * The shape of one generated class, resolved from the target and the class mutability (spec §6.2).
 */
final class ClassForm
{
    private bool $promoted;

    private bool $publicProperties;

    private bool $readonlyProperties;

    private bool $readonlyClass;

    private bool $getters;

    private bool $setters;

    private WitherStyle $withers;

    public function __construct(
        bool $promoted,
        bool $publicProperties,
        bool $readonlyProperties,
        bool $readonlyClass,
        bool $getters,
        bool $setters,
        WitherStyle $withers
    ) {
        $this->promoted = $promoted;
        $this->publicProperties = $publicProperties;
        $this->readonlyProperties = $readonlyProperties;
        $this->readonlyClass = $readonlyClass;
        $this->getters = $getters;
        $this->setters = $setters;
        $this->withers = $withers;
    }

    public function isPromoted(): bool
    {
        return $this->promoted;
    }

    public function hasPublicProperties(): bool
    {
        return $this->publicProperties;
    }

    public function hasReadonlyProperties(): bool
    {
        return $this->readonlyProperties;
    }

    public function isReadonlyClass(): bool
    {
        return $this->readonlyClass;
    }

    public function hasGetters(): bool
    {
        return $this->getters;
    }

    public function hasSetters(): bool
    {
        return $this->setters;
    }

    public function withers(): WitherStyle
    {
        return $this->withers;
    }
}
```

В `TargetProfile` добавить метод после `accessorsFor()`:

```php
    public function classFormFor(Mutability $mutability): ClassForm
    {
        $public = $this->accessorsFor($mutability)->equals(AccessorStyle::from(AccessorStyle::PUBLIC_PROPERTIES));
        $promoted = $this->supports(Capability::from(Capability::CONSTRUCTOR_PROMOTION));
        if (!$mutability->isImmutable()) {
            return new ClassForm($promoted, $public, false, false, !$public, !$public, WitherStyle::from(WitherStyle::NONE));
        }

        $readonly = $this->supports(Capability::from(Capability::READONLY_PROPERTIES));
        $readonlyClass = $this->supports(Capability::from(Capability::READONLY_CLASSES));
        if ($this->supports(Capability::from(Capability::CLONE_WITH))) {
            $withers = WitherStyle::CLONE_WITH;
        } elseif ($readonly) {
            // Readonly properties cannot be assigned on a clone before 8.5, so the copy goes through the constructor.
            $withers = WitherStyle::NEW_SELF;
        } else {
            $withers = WitherStyle::CLONE_ASSIGN;
        }

        return new ClassForm($promoted, $public, $readonly && !$readonlyClass, $readonlyClass, !$public, false, WitherStyle::from($withers));
    }
```

```php
<?php

declare(strict_types=1);

namespace MSSTC4PHP\DtoGenerator\Infrastructure\Emitter;

use LogicException;
use MSSTC4PHP\DtoGenerator\Domain\Model\ClassName;
use MSSTC4PHP\DtoGenerator\Domain\Model\ClassType;
use MSSTC4PHP\DtoGenerator\Domain\Model\ListType;
use MSSTC4PHP\DtoGenerator\Domain\Model\MapType;
use MSSTC4PHP\DtoGenerator\Domain\Model\MixedType;
use MSSTC4PHP\DtoGenerator\Domain\Model\NullableType;
use MSSTC4PHP\DtoGenerator\Domain\Model\ScalarType;
use MSSTC4PHP\DtoGenerator\Domain\Model\TypeModel;
use MSSTC4PHP\DtoGenerator\Domain\Model\UnionType;
use MSSTC4PHP\DtoGenerator\Domain\Target\Capability;
use MSSTC4PHP\DtoGenerator\Domain\Target\TargetProfile;
use PhpParser\Node;

/**
 * Native and PHPDoc forms of an IR type inside one namespace (spec §5.1). Classes outside the namespace are
 * fully qualified, so neither form resolves them against the file's namespace.
 */
final class TypeRenderer
{
    private const BUILTIN = ['int', 'float', 'string', 'bool', 'array', 'mixed', 'null'];

    private string $namespace;

    private TargetProfile $target;

    public function __construct(string $namespace, TargetProfile $target)
    {
        $this->namespace = $namespace;
        $this->target = $target;
    }

    public function native(TypeModel $type): ?string
    {
        if ($type instanceof ScalarType) {
            return $type->kind();
        }

        if ($type instanceof ClassType) {
            return $this->qualify($type->className());
        }

        if ($type instanceof ListType || $type instanceof MapType) {
            return 'array';
        }

        if ($type instanceof MixedType) {
            return $this->target->supports(Capability::from(Capability::MIXED_TYPE)) ? 'mixed' : null;
        }

        if ($type instanceof UnionType) {
            return $this->nativeUnion($type);
        }

        if ($type instanceof NullableType) {
            $inner = $this->native($type->inner());
            if ($inner === null) {
                return null;
            }

            return strpos($inner, '|') === false ? '?' . $inner : $inner . '|null';
        }

        throw new LogicException(sprintf('Type %s cannot be emitted yet.', $type->describe()));
    }

    /**
     * @return Node\Identifier|Node\Name|Node\NullableType|Node\UnionType|null
     */
    public function nativeNode(TypeModel $type): ?Node
    {
        $native = $this->native($type);
        if ($native === null) {
            return null;
        }

        if (strpos($native, '|') !== false) {
            return new Node\UnionType(array_map([self::class, 'single'], explode('|', $native)));
        }

        return strncmp($native, '?', 1) === 0 ? new Node\NullableType(self::single(substr($native, 1))) : self::single($native);
    }

    public function doc(TypeModel $type): string
    {
        if ($type instanceof ScalarType) {
            return $type->phpDoc() ?? $type->kind();
        }

        if ($type instanceof ClassType) {
            return $this->qualify($type->className());
        }

        if ($type instanceof ListType) {
            return 'list<' . $this->doc($type->item()) . '>';
        }

        if ($type instanceof MapType) {
            return 'array<array-key, ' . $this->doc($type->value()) . '>';
        }

        if ($type instanceof MixedType) {
            return 'mixed';
        }

        if ($type instanceof UnionType) {
            return implode('|', array_map([$this, 'doc'], $type->members()));
        }

        if ($type instanceof NullableType) {
            $inner = $type->inner();

            return $inner instanceof UnionType ? $this->doc($inner) . '|null' : '?' . $this->doc($inner);
        }

        throw new LogicException(sprintf('Type %s cannot be emitted yet.', $type->describe()));
    }

    public function needsDoc(TypeModel $type): bool
    {
        $native = $this->native($type);

        return $native === null || $native !== $this->doc($type);
    }

    private function nativeUnion(UnionType $type): ?string
    {
        if (!$this->target->supports(Capability::from(Capability::UNION_TYPES))) {
            return null;
        }

        $names = [];
        foreach ($type->members() as $member) {
            $name = (string) $this->native($member);
            $names[$name] = $name;
        }

        return implode('|', $names);
    }

    private function qualify(ClassName $name): string
    {
        return $name->namespace() === $this->namespace ? $name->shortName() : '\\' . $name->fqcn();
    }

    /**
     * @return Node\Identifier|Node\Name
     */
    private static function single(string $type): Node
    {
        if (strncmp($type, '\\', 1) === 0) {
            return new Node\Name\FullyQualified(substr($type, 1));
        }

        return in_array($type, self::BUILTIN, true) ? new Node\Identifier($type) : new Node\Name($type);
    }
}
```

У членов union нативный тип есть всегда: `UnionType` не допускает `mixed` и nullable. Поэтому `(string)` в `nativeUnion` безопасен и комментария не требует.

`src/Infrastructure/Emitter/DocBlock.php`:

```php
<?php

declare(strict_types=1);

namespace MSSTC4PHP\DtoGenerator\Infrastructure\Emitter;

/**
 * A PHPDoc block from a schema description and tags (spec §5.5).
 */
final class DocBlock
{
    private function __construct()
    {
    }

    /**
     * @param list<string> $tags
     */
    public static function render(?string $description, array $tags): ?string
    {
        $lines = [];
        $text = trim((string) $description);
        if ($text !== '') {
            foreach ((array) preg_split('/\r\n|\r|\n/', $text) as $line) {
                // "*/" inside the text would close the comment early.
                $lines[] = rtrim(str_replace('*/', '*\/', (string) $line));
            }
        }

        if ($tags !== []) {
            if ($lines !== []) {
                $lines[] = '';
            }

            array_push($lines, ...$tags);
        }

        if ($lines === []) {
            return null;
        }

        return "/**\n" . implode("\n", array_map(static fn (string $line): string => $line === '' ? ' *' : ' * ' . $line, $lines)) . "\n */";
    }
}
```

```php
<?php

declare(strict_types=1);

namespace MSSTC4PHP\DtoGenerator\Infrastructure\Emitter;

use PhpParser\Node\Stmt;
use PhpParser\PrettyPrinter\Standard;

/**
 * The standard printer with PSR-12 spacing: a blank line between members and top-level statements, none
 * between consecutive expression statements, and `declare(strict_types=1);` without the inner space.
 */
final class GeneratedCodePrinter extends Standard
{
    protected function pStmt_Declare(Stmt\Declare_ $node): string
    {
        return 'declare(' . $this->pCommaSeparated($node->declares) . ')'
            . ($node->stmts !== null ? ' {' . $this->pStmts($node->stmts) . $this->nl . '}' : ';');
    }

    protected function pStmts(array $nodes, bool $indent = true): string
    {
        $result = '';
        $previous = null;
        foreach ($nodes as $node) {
            if ($previous !== null && !($previous instanceof Stmt\Expression && $node instanceof Stmt\Expression)) {
                $result .= "\n";
            }

            $result .= parent::pStmts([$node], $indent);
            $previous = $node;
        }

        return $result;
    }
}
```

`src/Infrastructure/Emitter/PhpParserEmitter.php`:

```php
<?php

declare(strict_types=1);

namespace MSSTC4PHP\DtoGenerator\Infrastructure\Emitter;

use LogicException;
use MSSTC4PHP\DtoGenerator\Application\Port\CodeEmitter;
use MSSTC4PHP\DtoGenerator\Domain\Model\ClassKind;
use MSSTC4PHP\DtoGenerator\Domain\Model\ClassModel;
use MSSTC4PHP\DtoGenerator\Domain\Model\DocModel;
use MSSTC4PHP\DtoGenerator\Domain\Model\Identifier;
use MSSTC4PHP\DtoGenerator\Domain\Model\PropertyModel;
use MSSTC4PHP\DtoGenerator\Domain\Shared\DefaultValue;
use MSSTC4PHP\DtoGenerator\Domain\Target\ClassForm;
use MSSTC4PHP\DtoGenerator\Domain\Target\TargetProfile;
use MSSTC4PHP\DtoGenerator\Domain\Target\WitherStyle;
use PhpParser\BuilderFactory;
use PhpParser\Comment;
use PhpParser\Comment\Doc;
use PhpParser\Modifiers;
use PhpParser\Node;
use PhpParser\Node\Expr;
use PhpParser\Node\Stmt;
use PhpParser\PhpVersion as ParserPhpVersion;

/**
 * Renders one IR class as a PHP file in the shape the target dictates (spec §6.2).
 */
final class PhpParserEmitter implements CodeEmitter
{
    private const HEADER = '// @generated by msstc4php/dto-generator — DO NOT EDIT';

    private BuilderFactory $factory;

    public function __construct()
    {
        $this->factory = new BuilderFactory();
    }

    public function emit(ClassModel $class, TargetProfile $target): string
    {
        $this->assertSupported($class);
        $form = $target->classFormFor($class->mutability());
        $types = new TypeRenderer($class->name()->namespace(), $target);

        $members = [];
        if (!$form->isPromoted()) {
            foreach ($class->properties() as $property) {
                $members[] = $this->declaration($property, $form, $types);
            }
        }

        if ($class->properties() !== []) {
            $members[] = $this->constructor($class, $form, $types);
        }

        foreach ($class->properties() as $property) {
            array_push($members, ...$this->accessors($class, $property, $form, $types));
        }

        $node = $this->factory->class($class->name()->shortName())->addStmts($members)->getNode();
        $node->flags |= $this->modifiers($class->kind(), $form);
        self::document($node, DocBlock::render($class->doc()->description(), self::deprecation($class->doc())));

        $header = new Stmt\Nop();
        $header->setAttribute('comments', [new Comment(self::HEADER)]);
        $statements = [$header, new Stmt\Declare_([new Node\DeclareItem('strict_types', new Node\Scalar\Int_(1))])];
        $namespace = $class->name()->namespace();
        $statements[] = $namespace === '' ? $node : $this->factory->namespace($namespace)->addStmt($node)->getNode();

        $printer = new GeneratedCodePrinter([
            'phpVersion' => ParserPhpVersion::fromComponents($target->php()->major(), $target->php()->minor()),
            'shortArraySyntax' => true,
        ]);

        return $printer->prettyPrintFile($statements) . "\n";
    }

    private function assertSupported(ClassModel $class): void
    {
        $fqcn = $class->name()->fqcn();
        if ($class->parent() !== null) {
            throw new LogicException(sprintf('%s extends a class; inheritance is emitted from stage 4.', $fqcn));
        }

        if ($class->discriminator() !== null) {
            throw new LogicException(sprintf('%s has a discriminator; discriminators are emitted from stage 4.', $fqcn));
        }

        $attributes = $class->attributes() !== [];
        foreach ($class->properties() as $property) {
            $attributes = $attributes || $property->attributes() !== [];
        }

        if ($attributes) {
            throw new LogicException(sprintf('%s has attributes; attributes are emitted from stage 5.', $fqcn));
        }
    }

    private function modifiers(ClassKind $kind, ClassForm $form): int
    {
        $flags = $form->isReadonlyClass() ? Modifiers::READONLY : 0;
        if ($kind->isAbstract()) {
            return $flags | Modifiers::ABSTRACT;
        }

        return $kind->equals(ClassKind::from(ClassKind::FINAL)) ? $flags | Modifiers::FINAL : $flags;
    }

    private function declaration(PropertyModel $property, ClassForm $form, TypeRenderer $types): Stmt\Property
    {
        $builder = $this->factory->property($property->name());
        if ($form->hasPublicProperties()) {
            $builder->makePublic();
        } else {
            $builder->makePrivate();
        }

        if ($form->hasReadonlyProperties()) {
            $builder->makeReadonly();
        }

        $type = $types->nativeNode($property->type());
        if ($type !== null) {
            $builder->setType($type);
        }

        $node = $builder->getNode();
        self::document($node, $this->propertyDoc($property, $types));

        return $node;
    }

    private function constructor(ClassModel $class, ClassForm $form, TypeRenderer $types): Stmt\ClassMethod
    {
        $params = [];
        $tags = [];
        $body = [];
        foreach (self::constructorOrder($class) as $property) {
            $param = $this->param($property, $types, $property->default());
            if ($form->isPromoted()) {
                $param->flags = ($form->hasPublicProperties() ? Modifiers::PUBLIC : Modifiers::PRIVATE)
                    | ($form->hasReadonlyProperties() ? Modifiers::READONLY : 0);
                self::document($param, $this->propertyDoc($property, $types));
            } else {
                $tags = array_merge($tags, $this->paramTag($property, $types));
                $body[] = new Stmt\Expression(new Expr\Assign(self::fetch($property->name()), new Expr\Variable($property->name())));
            }

            $params[] = $param;
        }

        $node = $this->factory->method('__construct')->makePublic()->addParams($params)->addStmts($body)->getNode();
        self::document($node, DocBlock::render(null, $tags));

        return $node;
    }

    /**
     * @return list<Stmt\ClassMethod>
     */
    private function accessors(ClassModel $class, PropertyModel $property, ClassForm $form, TypeRenderer $types): array
    {
        $name = $property->name();
        $suffix = Identifier::asciiUpperFirst($name);
        $deprecation = self::deprecation($property->doc());
        $methods = [];

        if ($form->hasGetters()) {
            $getter = $this->factory->method('get' . $suffix)->makePublic()->addStmt(new Stmt\Return_(self::fetch($name)));
            $type = $types->nativeNode($property->type());
            if ($type !== null) {
                $getter->setReturnType($type);
            }

            $node = $getter->getNode();
            $returnTag = $types->needsDoc($property->type()) ? ['@return ' . $types->doc($property->type())] : [];
            self::document($node, DocBlock::render(null, array_merge($returnTag, $deprecation)));
            $methods[] = $node;
        }

        if ($form->hasSetters()) {
            $methods[] = $this->mutator('set' . $suffix, $property, $types, [
                new Stmt\Expression(new Expr\Assign(self::fetch($name), new Expr\Variable($name))),
                new Stmt\Return_(new Expr\Variable('this')),
            ]);
        }

        if (!$form->withers()->isNone()) {
            $methods[] = $this->mutator('with' . $suffix, $property, $types, $this->witherBody($class, $property, $form->withers()));
        }

        return $methods;
    }

    /**
     * @param list<Stmt> $body
     */
    private function mutator(string $method, PropertyModel $property, TypeRenderer $types, array $body): Stmt\ClassMethod
    {
        $node = $this->factory->method($method)
            ->makePublic()
            ->addParam($this->param($property, $types, null))
            ->setReturnType('self')
            ->addStmts($body)
            ->getNode();
        self::document($node, DocBlock::render(null, array_merge($this->paramTag($property, $types), self::deprecation($property->doc()))));

        return $node;
    }

    /**
     * @return list<Stmt>
     */
    private function witherBody(ClassModel $class, PropertyModel $property, WitherStyle $style): array
    {
        $name = $property->name();
        if ($style->equals(WitherStyle::from(WitherStyle::CLONE_WITH))) {
            $changes = new Expr\Array_([new Node\ArrayItem(new Expr\Variable($name), new Node\Scalar\String_($name))], ['kind' => Expr\Array_::KIND_SHORT]);

            return [new Stmt\Return_(new Expr\FuncCall(new Node\Name('clone'), [new Node\Arg(new Expr\Variable('this')), new Node\Arg($changes)]))];
        }

        if ($style->equals(WitherStyle::from(WitherStyle::NEW_SELF))) {
            $args = [];
            foreach (self::constructorOrder($class) as $other) {
                $args[] = new Node\Arg($other === $property ? new Expr\Variable($name) : self::fetch($other->name()));
            }

            return [new Stmt\Return_(new Expr\New_(new Node\Name('self'), $args))];
        }

        // The copy must not shadow the parameter, which carries the property's own name.
        $copy = $name === 'clone' ? 'copy' : 'clone';

        return [
            new Stmt\Expression(new Expr\Assign(new Expr\Variable($copy), new Expr\Clone_(new Expr\Variable('this')))),
            new Stmt\Expression(new Expr\Assign(new Expr\PropertyFetch(new Expr\Variable($copy), $name), new Expr\Variable($name))),
            new Stmt\Return_(new Expr\Variable($copy)),
        ];
    }

    private function param(PropertyModel $property, TypeRenderer $types, ?DefaultValue $default): Node\Param
    {
        $builder = $this->factory->param($property->name());
        $type = $types->nativeNode($property->type());
        if ($type !== null) {
            $builder->setType($type);
        }

        if ($default !== null) {
            $builder->setDefault($default->value());
        }

        return $builder->getNode();
    }

    /**
     * @return list<string>
     */
    private function paramTag(PropertyModel $property, TypeRenderer $types): array
    {
        return $types->needsDoc($property->type()) ? ['@param ' . $types->doc($property->type()) . ' $' . $property->name()] : [];
    }

    private function propertyDoc(PropertyModel $property, TypeRenderer $types): ?string
    {
        $var = $types->needsDoc($property->type()) ? ['@var ' . $types->doc($property->type())] : [];

        return DocBlock::render($property->doc()->description(), array_merge($var, self::deprecation($property->doc())));
    }

    /**
     * Required parameters first (spec §5.2): an optional one before a required one is deprecated since PHP 8.0.
     *
     * @return list<PropertyModel>
     */
    private static function constructorOrder(ClassModel $class): array
    {
        $required = [];
        $optional = [];
        foreach ($class->properties() as $property) {
            if ($property->isRequired()) {
                $required[] = $property;
            } else {
                $optional[] = $property;
            }
        }

        return array_merge($required, $optional);
    }

    /**
     * @return list<string>
     */
    private static function deprecation(DocModel $doc): array
    {
        return $doc->isDeprecated() ? ['@deprecated'] : [];
    }

    private static function fetch(string $property): Expr\PropertyFetch
    {
        return new Expr\PropertyFetch(new Expr\Variable('this'), $property);
    }

    private static function document(Node $node, ?string $doc): void
    {
        if ($doc !== null) {
            $node->setDocComment(new Doc($doc));
        }
    }
}
```
