## 2. Классы ошибок

- **A. Имена из одних знаков.** `+1` и `-1` (реакции GitHub) оба становятся `$_1` и case `_1`; `*` не даёт имени
  вовсе. Решение: ведущие `+`/`-` перед цифрой и одиночные знаки пишутся словами (`plus1`, `minus1`, `asterisk`) —
  только там, где сегодня ошибка, чтобы не менять уже сгенерированные имена.
- **B. Конфликт имён классов.** Имя inline-схемы (выведенное из пути или из `title`) совпадает с компонентом или с
  другой inline-схемой. Решение: inline-схема уступает: следующее по порядку выведенное имя, затем числовой суффикс.
- **C. Разные типы одного свойства в ветвях `allOf`.** По JSON Schema применяются обе ветви, то есть тип —
  пересечение. Решение: `TypeMeet` берёт более узкий тип, когда один допускает все значения другого (`mixed`,
  `string` ⊇ формат/enum, `float` ⊇ `int`, `T|null` ⊇ `T`, списки и карты поэлементно, `array<mixed>` ⊇ класс,
  объединения по членам); несовместимые остаются ошибкой.
- **D. Потомок повторно объявляет свойство родителя.** Решение: если объявление потомка только сужает значения
  (тот же PHP-вид: `null`, уточнение скаляра, enum; то же имя и default) — свойство остаётся у родителя с
  предупреждением, а мост проверяет сужение потомка `Property`/`Present`; класс, дата, список или карта поверх типа
  родителя, другой default — ошибка (PHP не сужает тип свойства в потомке).
- **E–G (OpenAI): unions.** Вариант, у которого уже есть родитель; вариант не `$ref` на объект; inline-объект в
  дискриминированном union; `allOf` на union — относятся к пункту 2 (`oneOf`/`anyOf`).

## 3. Итог (2026-10-14 UTC)

A–D сделаны (ветка ядра `feat/corpus-fixes`). GitHub: 5842 класса, все грузятся, метаданные Validator и Serializer
читаются; время 99 с с мостом против 43 с без него (профиль Stripe размазан, явного узкого места нет — кандидат на
отдельную оптимизацию). Дополнительно найдено и сделано: inline-объекты одного свойства (и его `items`/вариантов) в
нескольких ветвях `allOf` — один класс (`Registry::join`, `Composition::withCompanions`), иначе `TypeMeet` не
сводил два разных класса. Повторное объявление в потомке — свойство остаётся у родителя (мост пока не проверяет
сужение потомка — пробел, записан). OpenAI остаётся на пункт 2 (E–G).

## 4. Ревью (2026-10-14 UTC)

Слияние inline-объектов — только по пути без вариантов union (`Item`/`Value`), если ни один не цель `$ref` и второй
не говорит больше своих свойств (`allOf`, `additionalProperties`, `x-`, ключевые слова класса) — иначе прежняя
ошибка пересечения. Повтор у потомка отбрасывается только при сужении значений (см. D). `TypeMeet`: строковый класс —
только класс дат; карта допускает только классы, которые генерирует сборка (не `x-php-type`/форматы); при взаимном
допуске — более короткий тип; карты сводятся по значениям. Имена знаками — без учёта видов; написание, задевающее
другое имя, отменяется. Отложенные inline-типы (проигравший enum пересечения, enum отброшенного повтора) не
генерируются (`Superseded`). Предупреждение о занятом имени называет схему-владельца.

## 5. Перепрогон на 1.6.0 (2026-10-15 UTC)

Ветка `feat/corpus-fixes-2`. Petstore, Train, Stripe, GitHub — чисто, диагностика как была; GitHub 38–40 с с мостом
(было 99 с: ускорение пришло с предыдущими ветками, отдельная оптимизация пока не нужна). OpenAI — 6 ошибок трёх классов:

- **H. `allOf: [anyOf[…58 событий без дискриминатора], {stream_id}]`** (`ResponsesWebSocketStreamEvent`, Beta). Решение 2.4
  в силе: ошибка; текст теперь говорит, что член — `oneOf`/`anyOf`; в docs — обход через `exclude` источника.
- **I. Пересечение двух классов** (`prompt_cache_options`: `PromptCacheOptionsParam` и `ResponsePromptCacheOptionsParam`
  с теми же свойствами и ещё двумя). Решение: `ObjectShape::admits` — широкая схема говорит только свойства/`required`/
  аннотации, узкая содержит каждое её свойство с той же схемой значений и требует её `required`; один файл.
- **J. Повтор enum у потомка с пересекающимися значениями** (`status`: `in_progress|completed|incomplete` у родителя,
  `completed|incomplete|failed` у потомка). Решение: свойство остаётся у родителя с предупреждением, мост пишет `Choice`
  по пересечению (уже умел: `ValueConstraints::enumCases` отбрасывает чужие значения).

С `exclude: ['*ResponsesWebSocketStreamEvent']` OpenAI — 4227 классов, все грузятся. Попутно: `symfony/yaml` получил
CVE-2026-109413 — нижняя граница поднята (`^5.4.54 || ^6.4.45 || ^7.4.18 || ^8.1.6`).
