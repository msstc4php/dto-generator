# F2 — удалённые `$ref` (URL)

**Дата:** 2026-10-10 (UTC). **Статус:** решение принято автономно по поручению владельца 2026-10-10 («ссылки $ref на
внешние файлы и URL… потом этом»). Ссылки на файлы рядом со спецификацией уже поддержаны; F2 — ссылки на `http(s)://`.

## 1. Проблема

`$ref: 'https://schemas.example.com/common/v1/money.yaml#/Money'` сейчас — ошибка «Remote $ref … is not supported».
Генератор, который скачивает код из сети при каждом запуске, — это недетерминированная сборка, зависимость CI от сети и
поверхность атаки (SSRF, подмена содержимого, огромные ответы). Поддержка должна быть явной, ограниченной и
воспроизводимой.

## 2. Решение

Секция конфига:

```yaml
remoteRefs:
  allow:                         # префиксы URL; пусто (по умолчанию) — удалённые $ref запрещены
    - https://schemas.example.com/common/
  cacheDir: .dto-generator/remote   # относительно конфига
  timeout: 10                    # секунды на документ
```

- Удалённый `$ref` разрешён, только если его URL (нормализованный) начинается с одного из префиксов `allow`.
  Иначе — ошибка с подсказкой «add its prefix to remoteRefs.allow».
- Схемы URL — только `https` и `http`; `http` проходит только по префиксу, который сам начинается с `http://`.
  Префикс — абсолютный URL без userinfo, query и fragment.
- **Кэш.** Скачанный документ сохраняется в `cacheDir` (имя — `sha256(url)` + расширение, индекс `index.json`:
  URL → файл, время загрузки UTC, sha256 содержимого). Следующие запуски читают кэш и в сеть не ходят. Каталог
  предлагается коммитить: сборка без сети, ревью изменений чужих схем. Обновление — удалить файл или каталог.
- **Режимы.** `generate` (write) скачивает отсутствующее в кэше и пишет его. `--check` и `--dry-run` читают только
  кэш: отсутствующий документ — ошибка «… is not cached; run generate to fetch it».
- **Загрузка.** Без редиректов (3xx — ошибка с `Location`: разрешить конечный URL явно), проверка TLS, лимит 10 МБ,
  таймаут из конфига, ответ не 200 — ошибка. Формат: по расширению пути (`.json`, `.yaml`, `.yml`), иначе по
  `Content-Type`, иначе — JSON, затем YAML.

## 3. Ссылки внутри удалённых документов

- Относительный `$ref` в удалённом документе разрешается от его URL (RFC 3986: точки сегментов, `../`) и снова
  проходит проверку `allow`.
- Ссылка из удалённого документа на локальный файл (абсолютный путь, `file:`) — ошибка: чужой документ не читает
  файлы проекта.
- Идентичность документа — нормализованный URL (схема и хост в нижнем регистре, без порта по умолчанию, без
  fragment). Расположения схем (`SchemaLocation`) несут URL; диагностики показывают его как есть.

## 4. Архитектура

- Domain: `Shared\Url` — разбор, нормализация, разрешение относительной ссылки; `Reference::target()` возвращает
  `SchemaLocation` и для URL (схема не `http(s)` — ошибка модели).
- Application: `Config\RemoteRefsSettings` (allow, cacheDir, timeout); порт `Port\RemoteDocuments`
  (`load(url, bool $fetch): Document`, исключение `DocumentLoadFailed`); `Schemas\Load` решает, разрешён ли URL,
  и в каком режиме (`fetch` только в write).
- Infrastructure: `Remote\CachedRemoteDocuments` (кэш + декодирование через общий декодер `FileDocumentLoader`) и порт
  `Remote\Fetcher` с адаптером `StreamFetcher` (`file_get_contents` + stream context: `follow_location 0`,
  `ignore_errors`, `timeout`, `verify_peer`, лимит через `maxlen`); PHP 7.4.
- Composer-плагин, Docker и CLI работают через тот же use-case.

## 5. Вне рамок

- Аутентификация (заголовки, токены), прокси-настройки сверх переменных окружения PHP.
- Автоматическое обновление кэша по TTL / ETag.
- Схемы URL кроме http(s).

## 6. Тестирование

- Юнит: `Url` (нормализация, разрешение, отказ на userinfo/схемы), конфиг, проверка `allow`, режимы кэша.
- Интеграция: встроенный `php -S` на 127.0.0.1 с документами (`http://` префикс): генерация с удалённым `$ref`,
  относительная ссылка внутри удалённого документа, редирект → ошибка, 404 → ошибка, превышение размера → ошибка,
  `--check` без кэша → ошибка, с кэшем — без сети (сервер остановлен).
- Infection: MSI 100 %.
