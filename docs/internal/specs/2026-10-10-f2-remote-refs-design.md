# F2 — удалённые `$ref` (URL)

**Дата:** 2026-10-10 (UTC). **Статус:** решение принято автономно по поручению владельца 2026-10-10 («ссылки $ref на
внешние файлы и URL… потом этом»). Ссылки на файлы рядом со спецификацией уже поддержаны; F2 — ссылки на `http(s)://`.

## 1. Проблема

`$ref: 'https://schemas.example.com/common/v1/money.yaml#/Money'` сейчас — ошибка «Remote $ref … is not supported».
Генератор, который скачивает код из сети при каждом запуске, — это недетерминированная сборка, зависимость CI от сети и
поверхность атаки (SSRF, подмена содержимого, огромные ответы). Поддержка должна быть явной, ограниченной и
воспроизводимой.

## 2. Решение

Секция конфига:

```yaml
remoteRefs:
  allow:                         # префиксы URL; пусто (по умолчанию) — удалённые $ref запрещены
    - https://schemas.example.com/common/
  cacheDir: .dto-generator/remote   # относительно конфига
  timeout: 10                    # секунды на документ
```

- Удалённый `$ref` разрешён, только если его URL (нормализованный) начинается с одного из префиксов `allow`.
  Иначе — ошибка с подсказкой «add its prefix to remoteRefs.allow».
- Схемы URL — только `https` и `http`; `http` проходит только по префиксу, который сам начинается с `http://`.
  Префикс — абсолютный URL без userinfo, query и fragment.
- **Кэш.** Скачанный документ сохраняется в `cacheDir` (имя — `sha256(url)` + расширение, индекс `index.json`:
  URL → файл, время загрузки UTC, sha256 содержимого). Следующие запуски читают кэш и в сеть не ходят. Каталог
  предлагается коммитить: сборка без сети, ревью изменений чужих схем. Обновление — удалить файл и его запись в `index.json` или весь
  каталог.
- **Режимы.** `generate` (write) скачивает отсутствующее в кэше и пишет его. `--check` и `--dry-run` читают только
  кэш: отсутствующий документ — ошибка «… is not cached; run generate to fetch it».
- **Загрузка.** Свой HTTP/1.0-клиент на `stream_socket_client` (у http-обёртки PHP таймаут — на одно чтение, а
  заголовки не ограничены): без редиректов (3xx — ошибка с `Location`: разрешить конечный URL явно), проверка TLS и
  SNI, заголовки до 64 КБ, тело до 10 МБ, срок `timeout` на весь ответ (DNS не входит), ответ не 200 — ошибка. Формат: по расширению пути (`.json`, `.yaml`, `.yml`), иначе YAML при
  YAML-`Content-Type`, иначе JSON, если тело начинается с `{` (JSON-документ — объект), иначе YAML.

## 3. Ссылки внутри удалённых документов

- Относительный `$ref` в удалённом документе разрешается от его URL (RFC 3986 §5.2: точки сегментов, `../`, путь от
  корня `/x` — от хоста документа) и снова проходит проверку `allow`.
- Ссылка из удалённого документа с другой схемой (`file:`, `mailto:`) — ошибка: чужой документ не читает файлы
  проекта.
- Идентичность документа — нормализованный URL: схема и хост в нижнем регистре, без порта по умолчанию, экранирования
  unreserved-символов декодированы, остальные — в верхнем регистре, без dot-сегментов, без пустого query и fragment.
  Отвергаются символы вне RFC 3986, userinfo, хост вне reg-name/IP-literal, а в пути — `%2F`, `%5C`, `%25`, `%00`,
  `;` и байты не UTF-8: серверы декодируют или отбрасывают их так, что путь выходит за префикс (`..%2F`, `..;`,
  `%252e`). Расположения схем (`SchemaLocation`) несут URL; диагностики показывают его как есть.

## 4. Архитектура

- Domain: `Shared\Url` — `normalize`, `resolve`, `isUnder`, `hasScheme`; `Reference::target()` возвращает
  `SchemaLocation` и для URL.
- Application: `Config\RemoteRefsSettings` (allow, cacheDir, timeout); порт `Port\RemoteDocuments`
  (`load(url, cacheDir, timeout, bool $fetch): Document`, исключение `DocumentLoadFailed`); `Schemas\Load` решает,
  разрешён ли URL, и в каком режиме (`fetch` только в write).
- Infrastructure: `Remote\CachedRemoteDocuments` (индекс под `flock`, проверка записей, файлы по хешу содержимого,
  без символических ссылок; декодирование — общий `Document\DocumentDecoder`) и `Remote\Fetcher` с адаптером
  `StreamFetcher` — свой HTTP/1.0-клиент на `stream_socket_client`: принимает только нормализованный URL, TLS 1.2+ с
  проверкой сертификата и SNI, срок на весь ответ (рукопожатие включено), заголовки до 64 КБ без управляющих символов,
  `Content-Length` — одно число, тело ровно такой длины (короче — ошибка), без `Transfer-Encoding`.
- Composer-плагин, Docker и CLI работают через тот же use-case.

## 5. Вне рамок

- Аутентификация (заголовки, токены), прокси (переменные `HTTP_PROXY`/`HTTPS_PROXY` не используются).
- Автоматическое обновление кэша по TTL / ETag.
- Схемы URL кроме http(s).

## 6. Тестирование

- Юнит: `Url` (нормализация, разрешение, отказ на userinfo/схемы), конфиг, проверка `allow`, режимы кэша.
- Интеграция: встроенный `php -S` на 127.0.0.1 с документами (`http://` префикс): генерация с удалённым `$ref`,
  относительная ссылка внутри удалённого документа, редирект → ошибка, 404 → ошибка, превышение размера → ошибка,
  `--check` без кэша → ошибка, с кэшем — без сети (сервер остановлен).
- Infection: MSI 100 %.
